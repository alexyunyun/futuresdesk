# FuturesDesk · 期货工作台

纯静态运行的期货模拟工作台,部署在 GitHub Pages,无需服务器、无需本地进程:

**https://alexyunyun.github.io/futuresdesk/**

黑白极简风格,小圆角,大留白。行情与 K 线来自新浪财经公开接口(浏览器 JSONP 直连),AI 直连 DeepSeek,交易为浏览器本地模拟撮合,所有数据(账户、持仓、复盘日志、API Key)只保存在你自己的浏览器 localStorage 里。

## 功能模块

### 工作台
- **行情列表**:69 个品种按板块分组(黑色建材/有色/贵金属/能化/农产品/新能源/金融期货),搜索、自选(★)、点击联动图表与下单面板
- **图表**:分时图(价格+均价+量)、1/5/15/30/60 分钟、日线、周线;主图指标 MA/BOLL,副图 VOL/MACD/KDJ/RSI;十字光标 OHLC 读数;主力连续与 12 个月份合约切换
- **下单**:买入开多/卖出开空、开平仓、限价/市价、快捷手数、止盈止损(开仓附加)、条件单(触发后市价);预估名义/保证金/手续费
- **盘口**:买一/卖一,点击价格直接填入委托价
- **持仓管理**:浮动盈亏、占用保证金、平仓、反手、持仓级止盈止损、一键全部平仓
- **委托/成交**:挂单撤单、成交回报、拒绝原因
- **账户条**:动态权益、可用资金、保证金占用、风险度、当日盈亏、累计盈亏、手续费
- **资金**:资金曲线(对比初始资金基准线)+ 资金流水

### 行情中心
- 七大板块涨跌概览(点击卡片过滤)
- 全市场行情表:可按任意列排序;涨幅榜/跌幅榜/成交活跃/持仓增量排行

### AI 助手(DeepSeek)
- 流式对话;可勾选附带「当前合约行情快照」「我的持仓与账户」作为上下文
- 快捷指令:解读行情 / 技术面分析 / 持仓诊断 / 聊聊资金管理
- **API Key 在「设置」中填写,仅保存在本机浏览器 localStorage**,由浏览器直连 DeepSeek 官方接口

### 资讯
新浪财经滚动快讯,关键词筛选,5 分钟自动刷新

### 复盘日志
- 交易统计:平仓次数、胜率、盈亏比、平均盈亏、累计手续费
- 手写复盘 + **AI 点评本篇**(自动附上账户数据与近期复盘)

### 设置
- DeepSeek:API Key、模型(deepseek-chat / deepseek-reasoner)、测试连接
- 交易参数:手续费系数、保证金系数、重置账户(初始资金)
- 显示:涨跌配色(黑白 ▲▼ / 红涨绿跌)、行情刷新频率

## 模拟撮合规则
- 限价单:最新价穿越委托价即成交(以委托价撮合);市价单:最新价即时成交
- 手续费 = 名义价值 × 品种费率(万分比)× 手续费系数;保证金 = 最新价 × 乘数 × 手数 × 保证金率 × 保证金系数
- 风险度 = 保证金占用 / 动态权益;**超过 100% 自动市价强平全部持仓**
- 状态保存在浏览器 localStorage,换浏览器/清缓存会重置(可在「设置」中重置账户)

## 数据源(均为公开接口,浏览器直连)
| 数据 | 来源 |
|---|---|
| 实时行情 | 新浪期货服务中心 `Market_Center.getHQFuturesData`(JSONP) |
| 日K/分钟K | 新浪 `InnerFuturesNewService`(JSONP) |
| 资讯 | 新浪滚动新闻(JSONP) |
| AI | DeepSeek 官方 API(官方支持浏览器跨域) |

## 本地开发(可选)

纯静态,无任何构建与后端依赖:

```bash
npm start        # http://localhost:3210(仅本地预览用)
```

## 未包含(需要专业数据源/柜台)
实盘下单(需期货公司 CTP 柜台)、期权 T 型报价与组合策略、五档/十档订单流(JSONP 接口仅有一档)、套利腿执行、交易所节假日日历(时段判断按常规交易时间近似)。
