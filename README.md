# FuturesDesk · 期货工作台

本地运行的期货模拟工作台。黑白极简风格,行情来自新浪财经公开接口,K线图表基于 KLineCharts,交易为纯本地模拟撮合,AI 能力接入 DeepSeek。

![工作台](#) (启动后浏览器打开 http://localhost:3210 即可)

## 启动

```bash
cd futuresdesk
npm install
npm start        # http://localhost:3210
```

## 功能模块

### 工作台
- **行情列表**:69 个品种按板块分组(黑色建材/有色/贵金属/能化/农产品/新能源/金融期货),搜索、自选(★)、点击联动图表与下单面板
- **图表**:分时图(价格+均价+量)、1/5/15/30/60 分钟、日线、周线;主图指标 MA/BOLL,副图 VOL/MACD/KDJ/RSI;十字光标 OHLC 读数;主力连续与 12 个月份合约切换
- **下单**:买入开多/卖出开空、开平仓、限价/市价、快捷手数、止盈止损(开仓附加)、条件单(触发后市价);预估名义/保证金/手续费
- **五档盘口**:买卖五档量条,点击价格直接填入委托价(郑商所/中金所仅有买一卖一)
- **持仓管理**:浮动盈亏、占用保证金、平仓、反手、持仓级止盈止损设置、一键全部平仓
- **委托/成交**:挂单撤单、成交回报、拒绝原因
- **账户条**:动态权益、可用资金、保证金占用、风险度、当日盈亏、累计盈亏、手续费
- **资金**:资金曲线(对比初始资金基准线)+ 资金流水

### 行情中心
- 七大板块涨跌概览(点击卡片过滤)
- 全市场行情表:可按任意列排序;涨幅榜/跌幅榜/成交活跃/持仓增量排行

### AI 助手(DeepSeek)
- 流式对话;可勾选附带「当前合约行情快照」「我的持仓与账户」作为上下文
- 快捷指令:解读行情 / 技术面分析 / 持仓诊断 / 聊聊资金管理
- **API Key 在「设置」中填写,仅保存在本机浏览器 localStorage**,请求经本地服务转发至 DeepSeek

### 资讯
新浪财经滚动快讯,关键词筛选,5 分钟自动刷新

### 复盘日志
- 交易统计:平仓次数、胜率、盈亏比、平均盈亏、累计手续费
- 手写复盘 + **AI 点评本篇**(自动附上账户数据与近期复盘)

### 设置
- DeepSeek:API Key、模型(deepseek-chat / deepseek-reasoner)、测试连接
- 交易参数:手续费系数、保证金系数、重置账户(初始资金)
- 显示:涨跌配色(黑白 ▲▼ / 红涨绿跌)、行情刷新频率

## 模拟撮合规则
- 限价单:最新价穿越委托价即成交(以委托价撮合);市价单:最新价即时成交
- 手续费 = 名义价值 × 品种费率(万分比)× 手续费系数;保证金 = 最新价 × 乘数 × 手数 × 保证金率 × 保证金系数
- 风险度 = 保证金占用 / 动态权益;**超过 100% 自动市价强平全部持仓**
- 状态持久化在 `data/state.json`,重启不丢

## 数据源
| 数据 | 来源 |
|---|---|

| 日K/分钟K | 新浪 InnerFuturesNewService |

## 未包含(需要专业数据源/柜台)
实盘下单(需期货公司 CTP 柜台)、期权 T 型报价与组合策略、DOM 十档订单流(需 Level-2)、套利腿执行、交易所节假日日历(时段判断按常规交易时间近似)。
